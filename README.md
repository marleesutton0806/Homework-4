# Project Milestone Accessibility

## Accessibility Fixes

- I added labels to the contact form so each box is clear.
- I added a fieldset and legend to keep the contact form organized.
- I added an error style for required information that is missing.
- I added a focus outline so it is easier to see which box is selected.
- I tested all three pages with WAVE and fixed the errors that came up.
- I checked my colors to make sure the text is easy to read against the background.

## Gestalt Principles

- Proximity: I kept information that correlated close together, like the information inside my project sections.
- Similarity: I used the same colors, fonts, borders, and spacing throughout my website to keep everything consistent.

## Color Palette

I kept the same tan, brown, dark green, and white colors throughout my website so all three pages match.

## WAVE Issues and Fixes

1. WAVE reported "Possible Heading" on my name at the top of the Home page. I already had my name in an H1, so I removed the extra paragraph. This matters because repeated text that looks like a heading can make the page structure confusing for people using screen readers.

2. WAVE reported "Possible Heading" on the welcome paragraph. The same text was already being used as an H2, so I removed the repeated paragraph. This makes the heading structure clearer and removes unnecessary repeated information.

3. WAVE reported "Possible Heading" on my footer text. The paragraph text was styled large enough that it looked like a heading. I changed the footer text to 16px so it is clearly regular text. This helps users tell the difference between headings and other information on the page.
