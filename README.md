# Project Milestone Accessibility

## Accessibility Fixes

- I added labels to the contact form so each box is clear.
- I added a fieldset and legend to keep the contact form organized.
- I added an error style for required information that is missing.
- I added a focus outline so it is easier to see which box is selected.
- I tested all three pages with WAVE and fixed the errors that came up.
- I checked my colors to make sure the text is easy to read against the background.

## Gestalt Principles

- Proximity: I kept information that correlated close together, like the information inside my project sections.
- Similarity: I used the same colors, fonts, borders, and spacing throughout my website to keep everything consistent.

## Color Palette

I kept the same tan, brown, dark green, and white colors throughout my website so all three pages match.
